# К защите

Суть: выбираем тесты, чтобы за ограниченное время проверить как можно больше важных требований. Особь — 50 флагов «включён / исключён».

Чем меметический ГА отличается? Помимо размножения он пробует небольшие изменения каждого выбранного потомка. Эти попытки оплачиваются тем же бюджетом 5184 оценки.

Почему нет заявления о явном превосходстве? Средняя разница мала; доверительный bootstrap-интервал включает ноль. Полное покрытие достигают оба алгоритма.

Что доказано? Покрытие 102 — максимум суммы весов. Минимальная длительность при полном покрытии не доказана.

Откройте `REPORT.md`, покажите формулу, затем `results/runs.csv`, график и `test_model.py`. Объясните один слабый результат и одно ограничение исследования.
