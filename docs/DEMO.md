# Демонстрация — 6 минут

| Время | Действие | Что объяснить |
|---|---|---|
| 0:00–0:45 | Открыть README и data/tests.json | 50 тестов, 36 требований, ограничение 70 |
| 0:45–1:30 | Показать формулу и Problem.metrics | Взвешенное покрытие, предпочтение меньшего времени |
| 1:30–2:30 | Показать solve и счётчик evaluate | ГА, локальные соседи, равный бюджет |
| 2:30–3:10 | Запустить unittest и короткую серию в results_custom | Корректность и воспроизводимость |
| 3:10–4:20 | Открыть summary.csv и convergence.png полной серии | 30 seed, устойчивость и направление оптимизации |
| 4:20–5:10 | Показать coverage.png и solutions.json | Конкретные выбранные тесты и покрытие |
| 5:10–6:00 | Показать paired_comparison.json | Интервал включает ноль; ограничения синтетики |

Команды после установки зависимостей:

```bash
python -m unittest discover -v
python main.py --runs 1 --seed 47000 --output results_custom/demo
```

Полную серию не нужно запускать во время доклада: её исходные CSV и конфигурация уже приложены. При вопросе преподавателя можно запустить `python main.py --output results_custom/full`.
